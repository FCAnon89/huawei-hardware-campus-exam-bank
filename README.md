# 华为校招硬件岗模拟机考题库

一个可离线运行的交互式练习页面，面向华为硬件校招通用基础，包含逻辑、数电、模电、电源、计算机与接口、嵌入式、PCB与信号完整性、射频、测试、可靠性等方向。

## 使用方法

1. 下载或克隆本仓库。
2. 用现代浏览器打开 `index.html`，无需安装依赖，也不需要启动服务。
3. 设置题量、时长和知识方向后开始模拟；默认40题、60分钟。
4. 交卷后查看得分与答题情况，点击题号跳转到对应题目解析。

默认题型比例参考公开考生回忆（30道单选、10道多选），自定义题量时按约3:1随机抽取。题型、分值和考试内容以实际招聘通知为准。

## 题库说明

题目按固定题号保存；每场从选定范围随机抽取，不在同一场重复。可按知识方向筛选题库、搜索题干和选项，并查看答案、解析及对应来源链接。部分题目为公开考生回忆的改写，部分为依据公开考点编写的拓展练习，页面逐题标明类型与来源。

本项目不是华为官方发布或授权的题库，也不保证与任何正式考试相同。答案与解析用于复习参考；正式考试安排、范围与规则请以华为招聘官方信息为准。
